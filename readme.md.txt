ChatUI Project

Overview

This is a simple chat interface similar to ChatGPT.

It is built using:

- HTML
- CSS
- JavaScript

Features

- Send and display messages
- AI-like replies (mock responses)
- Typing indicator
- Welcome screen
- Sidebar with chat history
- Mobile responsive design
- Dark mode toggle

How to Run

1. Open the project folder
2. Double click `index.html`
3. Start using the chat

Note

This project uses fake AI responses and does not connect to any backend.
